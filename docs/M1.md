# M1: Reproduce LM1B-small (gate)

Goal: reimplement training and reproduce published LM1B-small genppl before any scaling.

## Steps
1. Environment: install requirements.txt (torch + cuda). No GPU detected in this dev box -> run on cluster.
2. Data: download `hazyresearch/ncm-datasets` and `hazyresearch/ncm-checkpoints` for reference eval.
   - `hf download hazyresearch/ncm-checkpoints --local-dir artifacts`
   - `hf download hazyresearch/ncm-datasets --repo-type dataset --local-dir data`
3. Baseline eval (no training): run NCM's eval to confirm harness works:
   - `python evaluate.py --config config/eval/lm1b-small.yaml --checkpoint-dir artifacts/lm1b-small`
4. Implement `training/train_tokenizer.py` (VQ-VAE recon + vq loss + nested dropout + corruption).
5. Train tokenizer on LM1B (or a subset) -> freeze -> save tokenizer.pt.
6. Implement `training/train_generator.py`:
   - Pre-tokenize corpus with tokenizer.get_ncm_inputs -> shards.
   - Train generator with per-level CE.
7. Eval generated checkpoint with `evaluate.py --config config/eval/lm1b-small.yaml`.
8. Gate: genppl within ~ published range (lower is better). If not, debug before scaling.
