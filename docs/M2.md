# M2: Tokenizer at scale

Goal: train and freeze the multiscale VQ-VAE tokenizer on the target corpus, then release `Veyra-One-Tokenizer`.

## Steps
1. Choose pre-tokenizer: bert-base-uncased (NCM default) vs Veyra BPE (open decision #3). Recommend: train Veyra BPE on target corpus for better compression.
2. Scale tokenizer: embed_dim 384 -> 768/1024, n_layers 6 -> 8/12, context 128 -> 512.
3. Train on diverse corpus (web, code, books), >= 100B tokens.
4. Validate reconstruction fidelity (token recovery rate) >= 95% on held-out.
5. Freeze tokenizer; save tokenizer.pt; release on HF as `veyra-ai/Veyra-One-Tokenizer`.
6. Gate: recovery rate + genppl of a small generator trained on this tokenizer.

## Open decisions
- Context length for tokenizer: 512 vs 1024.
- Number of levels: 12 (keep) vs adaptive.
- Codebook size: 8192 vs 16384.
